# ***Цумуги Широгане, абсолютный бот по поиску фильмов!***

Цумуги - бот, который может найти для вас почти любые фильмы или сериалы. Чтобы она это сделала, воспользуйтесь
командами, описанными ниже. Глобально команды делятся на три категории:

## *Общие команды*
- start - запуск бота
- help - вывод информации о командах и функциях

## *Функции для поиска*
- movie_search - поиск фильмов/сериалов по названию
- search_by_rating - поиск фильмов/сериалов по рейтингу
- low_budget_movie - поиск фильмов/сериалов с низким бюджетом
- high_budget_movie - ни за что не догадаетесь, что делает эта функция

## *Вывод истории поиска*
- history - непосредственно вывод истории запросов с возможностью увидеть выдачу по любому из них

## *Как запустить бота?*
Ничего сложного! Достаточно просто создать файл .env по образцу файла .env.template, вписать туда токен бота
и ключ от API, а после этого - запустить программу.
